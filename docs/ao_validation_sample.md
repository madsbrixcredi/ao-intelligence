# AO validation sample

This validation sample uses 20 deterministic random accounting offices from the AO master table. Raw data was not modified.

## Join method

Declaration rows are keyed by normalized `accounting_office_cvr` from the four declaration tables. Activity rows come from `DA_data`; each activity row is assigned to an accounting office by `requesting_company_name_fixed` / email-domain office signal, then mapped to a canonical `accounting_office_cvr` using the dominant `analyzed_company_vat` that matches a declaration CVR where possible. The final AO data mart joins declaration and activity aggregates on `accounting_office_cvr`.
